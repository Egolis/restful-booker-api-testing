# Restful Booker API Testing

Этот репозиторий содержит тестовую документацию и автоматизированные тесты для API [Restful Booker](https://restful-booker.herokuapp.com/apidoc/index.html).

##  Содержимое репозитория

- `Restful_Booker_API_Test.postman_collection.json` — экспортированная коллекция запросов Postman (v2.1) с автоматическими проверками (Test Scripts).
- `Restful_Booker_Test_Cases.xlsx` — таблица с позитивными и негативными тест-кейсами.
- `Bug_Report.xlsx` — отчёт о несоответствиях, найденных в официальной документации API.

##  Как запустить тесты

1. Установите [Postman](https://www.postman.com/).
2. Импортируйте файл `collection.json` (File → Import).
3. В настройках коллекции (Variables) убедитесь, что переменные `baseUrl` и `token` инициализированы.
4. Запустите запросы по порядку, начиная с `1. Auth - Create Token`. Токен и ID бронирования сохраняются в переменные коллекции автоматически.

##  Выполненные тесты

- Авторизация и получение токена
- Получение списка всех бронирований
- Создание нового бронирования
- Получение данных конкретного бронирования
- Полное обновление бронирования (PUT)
- Частичное обновление бронирования (PATCH)
- Удаление бронирования (DELETE)
- Проверка доступности API (Ping)

##  Найденные баги документации

1. В эндпоинте `PATCH /booking/:id` в curl-примере указан метод `PUT`.
2. Эндпоинты `DELETE /booking/:id` и `GET /ping` возвращают код `201 Created`, что противоречит стандартам REST (ожидалось 200 OK или 204 No Content).
3. В `POST /booking` структура тела запроса в таблице описания и в JSON-примере отличается.
